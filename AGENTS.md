# Agent Notes

## Start Of Work

At the start of a new session, read `HANDOFF.md`, `TODO.md`, and `README.md` as needed, then run `git status --short` before making changes.

## Keep Docs Current

This repo uses `TODO.md` as the shared task checklist. When completing a task, check `TODO.md` before finishing the turn. If the work completed or invalidated any checklist item, update the checkbox or wording in the same change set. Leave unrelated TODO items alone.

Keep `HANDOFF.md` current when a change affects current behavior, setup/run commands, verification steps, known tradeoffs, or next-session context. Do not treat `HANDOFF.md` as a permanent rulebook; durable agent workflow rules belong here in `AGENTS.md`.

## What Belongs Where

- `AGENTS.md`: standing instructions for future coding agents.
- `HANDOFF.md`: current project state, recent behavior decisions, known context, and suggested next-session checks.
- `TODO.md`: task checklist and product/documentation backlog.
- `README.md`: user-facing setup, usage, and API documentation.
