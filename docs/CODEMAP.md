# Code Map

Use this as the first stop when deciding where a change belongs.

## Runtime Flow

1. [`apps/web`](../apps/web/) signs in with Audiotool, lists or opens a project, selects tracks, and requests conversion.
2. [`apps/api`](../apps/api/) receives the request, opens the Audiotool project server-side, and exports the selected tracks to MIDI.
3. [`packages/audiotool-to-midi`](../packages/audiotool-to-midi/) owns Audiotool document inspection and MIDI rendering.
4. [`packages/midi-to-musicxml`](../packages/midi-to-musicxml/) consumes that MIDI—or an uploaded MIDI file—and generates MusicXML directly.
5. [`packages/score-to-audiotool`](../packages/score-to-audiotool/) parses MusicXML directly and owns Audiotool project/note-track writing.

## Top-Level Workspaces

- [`apps/web`](../apps/web/): React/Vite TypeScript browser app.
- [`apps/api`](../apps/api/): Express TypeScript API that composes the reusable packages.
- [`packages/audiotool-to-midi`](../packages/audiotool-to-midi/): Reusable TypeScript Audiotool-to-MIDI package.
- [`packages/midi-to-musicxml`](../packages/midi-to-musicxml/): Reusable TypeScript MIDI-to-MusicXML package.
- [`packages/score-to-audiotool`](../packages/score-to-audiotool/): Reusable TypeScript MusicXML score-to-Audiotool importer package.

## Experiments

- [`experiments/notation-ranker`](../experiments/notation-ranker/): Offline synthetic-data report and tuning harness for the candidate-ranking approach adapted into the direct app/API export path.

## API Guide

- [`apps/api/src/app.ts`](../apps/api/src/app.ts): Express app composition and route mounting.
- [`apps/api/src/routes/audiotool.ts`](../apps/api/src/routes/audiotool.ts): HTTP route flow for project listing, inspection, conversion, and `/audiotool/import`.
- [`apps/api/src/audiotool/request.ts`](../apps/api/src/audiotool/request.ts): Audiotool auth, request parsing, query/body option normalization, and request validation.
- [`apps/api/src/audiotool/output.ts`](../apps/api/src/audiotool/output.ts): Audiotool conversion work directories, MusicXML output files, zip archives, project serialization, and output names.
- [`apps/api/src/routes/convert.ts`](../apps/api/src/routes/convert.ts): Generic uploaded-MIDI conversion endpoint.
- [`apps/api/src/config/env.ts`](../apps/api/src/config/env.ts): Environment variables and defaults.
- [`apps/api/src/types.ts`](../apps/api/src/types.ts): API-local types for Audiotool auth, project details, MIDI files, and conversion options.
- [`apps/api/src/utils`](../apps/api/src/utils/): Shared query, response, and file helpers.
- [`apps/api/dist`](../apps/api/dist/): Ignored build output generated by `npm run build --workspace @midi-to-xml/api`.

## Audiotool-To-MIDI Package

- [`src/index.ts`](../packages/audiotool-to-midi/src/index.ts): Public package exports, including runtime helpers and shared option/result types.
- [`src/types.ts`](../packages/audiotool-to-midi/src/types.ts): Shared TypeScript types for Audiotool entities, manifests, MIDI output, sessions, and warnings.
- [`src/session.ts`](../packages/audiotool-to-midi/src/session.ts): Audiotool SDK sessions and project open/inspect helpers.
- [`src/project-reference.ts`](../packages/audiotool-to-midi/src/project-reference.ts): Accepted project reference formats and normalization.
- [`src/entities.ts`](../packages/audiotool-to-midi/src/entities.ts): Audiotool/Nexus entity access helpers.
- [`src/tracks.ts`](../packages/audiotool-to-midi/src/tracks.ts): Track manifest construction, track selection, region/note lookup, tempo, and time signature extraction.
- [`src/notation-classification.ts`](../packages/audiotool-to-midi/src/notation-classification.ts): Device-type classification for notation export defaults and warnings.
- [`src/render`](../packages/audiotool-to-midi/src/render/): MIDI export split into orchestration, track selection/warnings, MIDI construction, and note-region expansion.
- [`src/ticks.ts`](../packages/audiotool-to-midi/src/ticks.ts): Audiotool tick to MIDI tick conversion.
- [`dist`](../packages/audiotool-to-midi/dist/): Ignored build output generated by `npm run build --workspace @midi-to-xml/audiotool-to-midi`.

## MIDI-To-MusicXML Package

- [`src/index.ts`](../packages/midi-to-musicxml/src/index.ts): Public package exports, including runtime helpers and shared option/result types.
- [`src/types.ts`](../packages/midi-to-musicxml/src/types.ts): Shared TypeScript types for quantization, notation notes, and conversion results.
- [`src/midi.ts`](../packages/midi-to-musicxml/src/midi.ts): MIDI file validation, canonical-MIDI orchestration, direct conversion, and generated-file cleanup.
- [`src/quantizer.ts`](../packages/midi-to-musicxml/src/quantizer.ts): Multi-grid MIDI quantizer used before direct notation conversion.
- [`src/notation-ranker`](../packages/midi-to-musicxml/src/notation-ranker/): Candidate generation and heuristic selection, split into plans, duration math, event grouping, feature extraction/scoring, and orchestration.
- [`src/rhythm`](../packages/midi-to-musicxml/src/rhythm/): Executable rhythm grammar split into declarative rules, meter analysis, duration spelling, event cleanup, and shared contracts.
- [`src/direct-musicxml`](../packages/midi-to-musicxml/src/direct-musicxml/): Direct writer split into MIDI normalization, event construction, duration notation, beam/tuplet grouping, note serialization, and score serialization.
- [`dist`](../packages/midi-to-musicxml/dist/): Ignored build output generated by `npm run build --workspace @midi-to-xml/midi-to-musicxml`.

## Score-To-Audiotool Package

- [`src/index.ts`](../packages/score-to-audiotool/src/index.ts): Public package exports for score import analysis and Audiotool writing.
- [`src/musicxml`](../packages/score-to-audiotool/src/musicxml/): Direct `.musicxml`, `.xml`, and compressed `.mxl` import split into archive reading, ordered-XML helpers, part parsing, shared utilities, and plan assembly.
- [`src/score.ts`](../packages/score-to-audiotool/src/score.ts): Score-input validation and direct MusicXML import-plan orchestration.
- [`src/audiotool.ts`](../packages/score-to-audiotool/src/audiotool.ts): Audiotool project creation, config setup, Gakki/mixer/note-track/note-region writing, and part selection.
- [`src/types.ts`](../packages/score-to-audiotool/src/types.ts): Shared TypeScript types for import plans, warnings, results, and minimal Audiotool client/document interfaces.
- [`dist`](../packages/score-to-audiotool/dist/): Ignored build output generated by `npm run build --workspace @midi-to-xml/score-to-audiotool`.
